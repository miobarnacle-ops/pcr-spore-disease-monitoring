# 高配摆式悬挂底盘参数

## 已确认型号

- 底盘：WHEELTEC高配摆式悬挂四驱；
- 电机：MD36L-P27，24 V、60 W、1:27减速比；
- 编码器：500线AB相GMR编码器，STM32编码器模式四倍频；
- 轮胎：6英寸越野轮，标称直径152 mm、宽度约48 mm；
- 电池：24 V、6000 mAh；
- 裸车质量：7.6 kg。

## 固件运动学参数

固件车型应对应以下组合：

```text
SENIOR_4WD_BS + MD36N_27 + GMR_500 + WheelDiameter_4WD_152
```

当前预置值是：

```text
半轮距       0.176 m
半轴距       0.150 m
轮径         0.152 m
减速比       27
编码器线数   500
四倍频       4
每轮一圈计数 54000
```

固件中的轮距和轴距参与四驱滑移转向运动学，包含厂家经验值，不应仅因为图纸尺寸不同就
直接覆盖。应根据重复直线和原地旋转实测结果标定“有效轮径”和“有效旋转参数”。

## 当前实测基线

- 3.000 m编码器目标对应卷尺距离约3.05 m；
- 失联停车已经通过一次现场测试；
- 90°和360°原地旋转表现正常，但还需要把实际测量角度写入测试记录；
- 串口状态反馈约20 Hz。

每次重新烧录固件、更换轮胎气压、显著改变载荷或改变地面材质后，应重新检查直线距离、
横向偏移和旋转误差。
