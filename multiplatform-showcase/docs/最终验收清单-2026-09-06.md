# 《穗巡》多端展示应用最终验收清单

验收日期：2026-09-06；桌面 Logo 修复复验：2026-09-10  
验收目标：可安装、可重复操作、可用于介绍视频拍摄

## 功能与内容

- [x] 启动过场展示 Logo、道路/定位点、DNA 轨迹、应用名称和穗巡项目团队。
- [x] 桌面端包含综合态势、地块巡检、PCR 检测、风险预警、机器人状态五个页面。
- [x] 手机端包含首页、巡检、分析、项目四个页面，并锁定竖屏。
- [x] 手机分析页支持 3D、5D、7D 风险趋势切换。
- [x] 桌面端支持自动导览五阶段；手机端支持自动导览四阶段。
- [x] 自动导览支持中途停止、手动接管和重置。
- [x] 正式团队名称已统一为“穗巡项目团队”。
- [x] 展示界面仅保留弱化“演示模式”标识。

## 工程与安全

- [x] `npm run check` 通过。
- [x] `npm run audit:security` 通过，0 vulnerabilities。
- [x] 页面 CSP 禁止网络连接。
- [x] Electron 外壳拦截 HTTP、HTTPS、WebSocket、窗口跳转、权限和下载。
- [x] Android 清单不申请 INTERNET 权限。
- [x] Electron 渲染进程启用 contextIsolation、sandbox，关闭 nodeIntegration。

当前交付面向项目展示和视频拍摄，不面向公开分发。Android 包使用 Debug 签名；Windows 包未配置商业代码签名证书。应用内全部数据为本地模拟数据，不连接真实设备。
