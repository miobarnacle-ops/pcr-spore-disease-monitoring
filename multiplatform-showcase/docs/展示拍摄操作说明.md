# 《穗巡》多端展示应用拍摄操作说明

## Windows

1. 优先使用 `release/desktop/穗巡-展示应用-0.1.0.exe` 完成安装；需要快速拍摄时可直接双击 portable 版本。
2. 启动后等待品牌过场结束，点击右上角“自动演示”。
3. 应用将依次展示综合态势、地块巡检、PCR 检测、风险预警和机器人状态，全程约 40 秒。
4. 点击任一左侧导航可立即停止自动导览并手动接管；点击“重置”返回统一起点。

## Android

1. 安装 `release/mobile/穗巡-展示应用-0.1.0-debug.apk`；如系统提示来源确认，仅为本地安装授权。
2. 建议关闭自动旋转并使用竖屏录制，应用自身已锁定为竖屏。
3. 启动后等待品牌过场结束，点击顶部“导览”。
4. 应用将依次展示首页、巡检、分析和项目，全程约 40 秒。
5. 点击底部任一导航可手动接管；在“项目”页点击“重置演示状态”返回首页。

## 推荐拍摄顺序

品牌过场 → 桌面综合态势 → 自动巡检路线 → PCR 阳性样本 → 风险趋势 → 手机端自动导览 → 双端 Logo 收尾。

所有数据均为稳定的本地演示数据，不依赖网络或真实设备，重复启动后画面保持一致。
