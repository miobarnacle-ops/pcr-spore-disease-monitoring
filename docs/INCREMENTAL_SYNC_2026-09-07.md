# 2026-09-07 项目进展增量同步记录

> 本次同步基于公开仓库 `main` 分支最近提交，补充自上一版公开基线之后形成的源码、报告材料、验收证据和可交付发行包。

## 1. 多端展示应用

新增 `multiplatform-showcase/`，用于“穗巡”控制台的离线多端展示：

- Vite + React 共享界面与离线数据；
- Electron Windows 桌面端工程及安装包/便携版；
- Capacitor Android 工程及 Debug APK；
- 品牌素材、桌面/移动端适配、拍摄操作说明、执行状态和最终验收记录。

保留源码、Android 工程、验收截图和最终发行包；排除 `dist/`、Gradle 缓存、Capacitor 生成资产及 Windows `win-unpacked/` 解包目录。

## 2. 报告撰写材料

新增三模块报告的写作计划、第一版初稿、审计润色版和自我审计记录，覆盖：

- SLAM + RTK + 覆盖路径规划自主巡检方案；
- 总控制台与电脑/手机双端控制；
- PCR 观测驱动的孢子扩散预测与预警。

材料中区分了已实现、合成/离线验证、待补实测数据和不能提前宣称的结论边界，便于后续成员回填图表、日志和硬件测试结果。

## 3. Web 与扩散算法增量

同步 `spore-monitor-web/` 在上一版基线后的算法和验证更新，包括：

- 扩散、侵染窗口、数据同化和模型对比相关实现调整；
- 高斯烟羽基线与重构扩散算法的对比实验计划；
- 轻量化基准结果、报告对比实验计划、合成观测数据、场景指标和热力图；
- 对应的 Python 实验脚本、测试和可追溯产物。

当前对比材料以受控合成/离线实验为证据，不能替代真实农田观测，也不直接等同于田间准确率。

## 5. 成员使用提示

克隆仓库后，按各子项目 README 安装依赖。大文件使用 Git LFS 获取；如只进行源码、报告或离线算法开发，可先不执行 `git lfs pull`。涉及实车、串口、RTK、雷达或运动控制的任务，仍需负责人单独提供私密参数并按现场安全规程执行。
