## 0-1. 部署实录（2026-08-14 晚，agent 远程执行）

> ⚠️ **本清单 §2~§7 的原生 22.04 流程已作废**，实际部署走了不同路线，以下为实际发生的事情：

1. **首次尝试（22.04 镜像）失败**：Ubuntu 源里的 rpi-imager 1.7.2 过旧，其列表中的 22.04 镜像不含 Pi 5 设备树（bcm2712），Pi 5 根本无法启动（绿灯不闪、machine-id 为空）。
2. **决策 D2 修订**：改刷 **Ubuntu Server 24.04.4 LTS (arm64)**（清华镜像下载、SHA256 校验、dd 直写），**ROS 2 Humble 以 Docker 容器方式运行**（`ros:humble-ros-base` + host 网络 + privileged + 设备直通），与 PC/7月基线保持同版本。
3. **SSH 故障修复**：24.04.4 镜像 bug——`/etc/ssh/ssh_host_*` 全是 0 字节占位文件，sshd 报 `no hostkeys available` 循环失败。在本机生成密钥后拷入卡内 `/etc/ssh/` 解决（密钥与架构无关）。
4. **已完成**：apt 清华源（host+container）、Docker 29.1.3、镜像加速、`ros:humble-ros-base` 拉取、工作区传入 `/home/pi/spore_patrol_ws`（挂载到容器 `/ws`）、colcon/robot_localization/slam_toolbox 安装、YDLidar-SDK arm64 编译安装、**8 包 colcon build 全部通过**。
5. **容器使用方式**：树莓派上执行 `humble`（已写入 pi 的 bashrc 别名）= `sudo docker exec -it humble bash`，进入即自动 source ROS/工作区环境，ROS_DOMAIN_ID=77。
6. 容器内 ROS apt 源注意：`/etc/apt/sources.list.d/ros2.sources` 需将 `Types: deb deb-src` 改为 `Types: deb`（deb-src 在清华镜像 404 会拖垮整个 apt update）。

## 0. 关键决策与安全须知

**系统版本（重要，勿错）**：必须烧录 **Ubuntu Server 22.04 LTS（64 位 / arm64）**。
ROS 2 Humble 只支持 Ubuntu 22.04；**24.04 只能装 ROS 2 Jazzy，与现有仓库代码不兼容**。树莓派 Imager 列表里 24.04 排在前面，选择时务必认准 22.04。

安全须知（来自底盘测试规范）：

1. 首次通电前把四个车轮**可靠架空**（STM32 固件上电可能执行电机自检）；
2. 小车旁必须有人能立即按急停或断总电；
3. 先运行只读监听和停车命令，再做运动测试；
4. 每次只改一个变量，改前后记录。

## 2. 步骤 1：烧录系统（在烧录电脑上）

1. 下载安装 [Raspberry Pi Imager](https://www.raspberrypi.com/software/)。
2. 选择设备：**Raspberry Pi 5**。
3. 选择操作系统：**Other general-purpose OS → Ubuntu → Ubuntu Server 22.04 LTS（64-bit）**。
   ⚠️ 不要选成 24.04！如果列表里没有 22.04，用"Use custom"手动烧录从 `cdimage.ubuntu.com/ubuntu-server/releases/22.04/release/` 下载的 `ubuntu-22.04.5-preinstalled-server-arm64+raspi.img.xz`（国内可用清华镜像站 `mirrors.tuna.tsinghua.edu.cn/ubuntu-cdimage/` 加速）。
4. 选择存储卡，点 Next → Edit Settings，配置：
   - 主机名：`sporepi`
   - 用户名/密码：自己的账号（下文以 `miobarnacle` 为例）
   - 勾选 **Enable SSH**（密码方式即可）
   - WiFi：**用手机热点**（学校 WiFi 是开放网络+门户认证，无头 Pi 无法完成网页认证，且有客户端隔离会挡 SSH/DDS）。热点设固定密码，烧录电脑也连同一热点；国家 `CN`
   - 时区 `Asia/Shanghai`
5. 确认写入（会清空卡），等待完成。
6. 卡插回树莓派，接电源开机，等待 3–5 分钟首次启动完成。

## 3. 步骤 2：SSH 连接

在烧录电脑（与本机同一 WiFi）上：

```bash
ssh <PI_USER>@<VEHICLE_HOST>
# 若 .local 解析失败：
#   1) 查路由器后台 DHCP 设备列表找 IP，直接 ssh <PI_USER>@<IP>
#   2) 或临时接键盘+显示器
```

连不上时在树莓派上装 avahi（接屏操作一次即可）：`sudo apt install avahi-daemon`。

## 4. 步骤 3：系统初始化（SSH 内执行）

```bash
# （可选，国内提速）换清华源
sudo sed -i 's|ports.ubuntu.com/ubuntu-ports|mirrors.tuna.tsinghua.edu.cn/ubuntu-ports|g' /etc/apt/sources.list

sudo apt update && sudo apt full-upgrade -y
sudo apt install -y avahi-daemon git curl build-essential cmake
sudo timedatectl set-timezone Asia/Shanghai
sudo reboot
```

## 5. 步骤 4：安装 ROS 2 Humble

```bash
# locale
sudo apt install -y locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

# apt 源
sudo apt install -y software-properties-common
sudo add-apt-repository universe
sudo apt update && sudo apt upgrade -y

# ROS 密钥与仓库（默认官方源）
sudo apt install -y curl
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
```

（可选，国内提速：上面最后一条改为清华 ROS 2 镜像）

```bash
echo "deb [arch=arm64 signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] https://mirrors.tuna.tsinghua.edu.cn/ros2/ubuntu jammy main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
```

安装：

```bash
sudo apt update
sudo apt install -y ros-humble-desktop ros-dev-tools \
  ros-humble-slam-toolbox ros-humble-robot-localization \
  ros-humble-teleop-twist-keyboard
```

> `ros-humble-desktop` 约 2 GB，装完约需 30–60 分钟（视网速）。SD 卡 64 GB 足够。

## 6. 步骤 5：传输工作区（在烧录电脑上执行）

把当前 `spore-vehicle-nav` 仓库打包传给树莓派（排除编译产物）：

```bash
cd <REPO_ROOT>
tar czf /tmp/spore_ws_src.tar.gz \
  --exclude='build' --exclude='install' --exclude='log' --exclude='.vendor' \
  spore-vehicle-nav
scp /tmp/spore_ws_src.tar.gz <PI_USER>@<VEHICLE_HOST>:~/
```

（若两机不在同一网络：拷 U 盘再传到树莓派家目录。）

在树莓派上解压为工作区：

```bash
mkdir -p ~/spore_patrol_ws
tar xzf ~/spore_ws_src.tar.gz -C ~/spore_patrol_ws --strip-components=1
ls ~/spore_patrol_ws   # 应看到 src tests tools docs maps 等
```

## 7. 步骤 6：编译工作区（树莓派上）

```bash
cd ~/spore_patrol_ws
source /opt/ros/humble/setup.bash

# 编译 YDLidar-SDK（arm64）并拉取固定版本驱动源码
bash tools/setup_ydlidar_dependencies.sh
source tools/ydlidar_env.sh

colcon build --symlink-install
source install/setup.bash
```

> 编译约 10–20 分钟。若 GitHub 拉取慢：给脚本配置代理，或将脚本内 URL 前加 `https://ghproxy.net/` 前缀后重跑。

## 8. 步骤 7：环境变量固化

```bash
cat >> ~/.bashrc <<'EOF'
source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=77
[ -f ~/spore_patrol_ws/tools/ydlidar_env.sh ] && source ~/spore_patrol_ws/tools/ydlidar_env.sh
[ -f ~/spore_patrol_ws/install/setup.bash ] && source ~/spore_patrol_ws/install/setup.bash
EOF
source ~/.bashrc
```

⚠️ **ROS_DOMAIN_ID=77 要同时在烧录电脑上设置**（`echo 'export ROS_DOMAIN_ID=77' >> ~/.bashrc`），否则 PC 与树莓派互相看不到话题。

串口权限：

```bash
sudo usermod -aG dialout $USER
# 重新登录生效：exit 后重新 ssh
groups | grep dialout   # 确认
```

## 9. 步骤 8：底盘闭环验证（先只读，后运动）

**安全：车轮架空 + 急停在手再开始！**

```bash
cd ~/spore_patrol_ws

# 1) 找串口（C50C 一般是 /dev/ttyACM0）
python3 tests/chassis_serial/chassis_serial_test.py ports

# 2) 只读监听 10 秒（应看到 ~20Hz 状态反馈帧）
python3 tests/chassis_serial/chassis_serial_test.py listen --port /dev/ttyACM0 --duration 10

# 3) 失联停车测试（具体参数先看帮助）
python3 tests/chassis_serial/chassis_serial_test.py failsafe --help

# 4) 架空低速运动 2 秒
python3 tests/chassis_serial/chassis_serial_test.py motion --port /dev/ttyACM0 --vx 0.08 --duration 2
```

通过后跑 ROS 2 驱动：

```bash
# 终端1
ros2 launch spore_patrol_bringup hardware.launch.py port:=/dev/ttyACM0
# 终端2
ros2 topic hz /odom
ros2 topic echo /imu/data_raw --once
ros2 topic echo /battery_state --once
ros2 topic echo /diagnostics --once
# 键盘遥控（架空验证 /cmd_vel 链路；落地后低速短距）
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

## 10. 步骤 9：PC 端远程联调

烧录电脑（同 WiFi、同 ROS_DOMAIN_ID=77、装有 ROS 2 Humble + RViz）：


## 12. 常见问题

| 现象 | 原因/处理 |
|---|---|
| Pi 频繁重启、闪电图标 | 供电不足；换官方 27W 或 5V/5A PD；`dmesg \| grep -i voltage` 查证 |
| 学校 WiFi 连上但 SSH 不通/无外网 | 开放网络需门户认证，无头机无法完成；改用手机热点（推荐）或随身路由器 |
| ssh <VEHICLE_HOST> 失败 | avahi 未装/不同网段；查路由器 IP 直连 |
| apt/ROS 下载极慢 | 换清华镜像（步骤 3、5） |
| GitHub 克隆失败 | ghproxy 前缀或代理 |
| colcon 编译卡死/被杀 | 内存不足（一般 8GB 不会）；降低并行 `colcon build --parallel-workers 2` |
| PC 看不到 Pi 话题 | ROS_DOMAIN_ID 不一致或 WiFi 禁组播（见步骤 10） |
| /dev/ttyACM0 变号 | 换 USB 口引起；建议底盘线固定插同一口，后续为底盘也配 udev 规则 |
