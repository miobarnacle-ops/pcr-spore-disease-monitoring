# 模拟农田搭建与建图测试

本文档是阶段 C 的当前执行入口。模拟场景源代码、车端导航和地图验收工具均已同步
到本工作区。旧“穗巡”平台不参与场景、建图或路线测试。

## 1. 固定场地基线

场景配置：

| 项目 | 首轮基线 |
|---|---:|
| 场地 | 8.0 m × 6.0 m |
| 模拟垄 | 3 条，沿 X 方向 |
| 垄体尺寸 | 长 4.80 m、宽 0.22 m、高 0.50 m |
| 垄中心线 | Y = -1.42、0、+1.42 m |
| 通道净宽 | 1.42 - 0.22 = 1.20 m |
| 地头 | (8.00 - 4.80) / 2 = 1.60 m |
| 激光扫描高度 | 0.35 m，位于垄体高度范围内 |
| 首轮障碍 | 不放置静态/动态障碍 |
| 地图分辨率目标 | 0.05 m/cell |

坐标原点在场地几何中心，+X 沿垄方向，+Y 指向北侧。仿真机器人从
`(-2.00, -0.71, 0)` 出发，位于第 1、2 条垄之间并朝 +X。正式场地采用
“净通道 1.20 m”约束，因此不能把此前 1.0 m 中心距的小尺度双垄试验直接
当作本阶段场地尺寸。

唯一配置文件和世界文件：

```text
src/spore_patrol_sim/config/farmland_layout.json
src/spore_patrol_sim/worlds/farmland_8x6.world
```

## 2. 开始 ROS 2/Gazebo 前的离线检查

在开发电脑执行：

```bash
cd /path/to/spore-vehicle-nav
# ROS 2 Humble 的 apt 工具使用系统 Python 3.10；若 Anaconda 在 PATH 前面，先调整 PATH。
export PATH=/opt/ros/humble/bin:/usr/bin:/bin:$PATH
python3 tools/validate_farmland_layout.py
gz sdf -k src/spore_patrol_sim/worlds/farmland_8x6.world
python3 -m unittest discover -s tests/sim -p 'test_*.py'
```

这一步只读检查 JSON、SDF、通道/地头/激光高度和地图验收器，不连接树莓派、
串口或真实小车。

## 3. 仿真建图链

在已安装 ROS 2 Humble、Gazebo Classic 和本工作区的机器上，先构建：

```bash
cd /path/to/spore-vehicle-nav
source /opt/ros/humble/setup.bash
colcon build --symlink-install \
  --packages-select spore_patrol_description spore_patrol_sim
source install/setup.bash
```

手工启动入口（不自动移动）：

```bash
ros2 launch spore_patrol_sim sim.launch.py \
  gui:=false rviz:=false slam:=true use_sim_time:=true
```

推荐使用一次性无 GUI 烟测脚本，它会等待 `/scan`、`/odom`、`/map`，按固定低速
闭环轨迹发布仿真专用 `/cmd_vel`（默认仿真控制量 0.20 m/s，可用环境变量
`SIM_MAPPING_SPEED` 调整；该数值不代表实车速度），保存：

```text
results/<时间>_sim_farmland_8x6/
├── simulation.log
├── trajectory.log
├── map_saver.log
├── posegraph_saver.log
├── sim_farmland_8x6.yaml
├── sim_farmland_8x6.pgm
├── sim_farmland_8x6.posegraph / .data
├── map_validation.log
├── farmland_map_validation.log
└── farmland_layout.json
```

执行：

```bash
tools/sim_mapping_smoke.sh
```

仅检查节点启动、不发布仿真运动命令：

```bash
tools/sim_mapping_smoke.sh --no-drive
```

地图保存后还应确认 `map_validation.log` 为 `PASS saved map`。它检查 PGM/YAML
结构、地图覆盖范围、已知栅格比例和非空占用物；重影、闭环对齐和 TF 连续性仍
需查看 `farmland_map_validation.log` 和 RViz/rosbag 或后续轨迹分析，不能由图片尺寸单独证明。
后者针对本场景的三条垄检查连续覆盖、相对中心线偏移和轨迹离散，默认阈值为
覆盖率 ≥75%、中心线偏移 ≤0.20 m、离散 ≤0.12 m。

需要诊断回环误配时，可通过 `SIM_SLAM_PARAMS_FILE` 指定
`tests/sim/fixtures/sim_mapping_odom_only.yaml`（仅用于隔离里程计影响）或
`sim_mapping_scan_no_loop.yaml`；正式基线仍使用
`src/spore_patrol_sim/config/sim_mapping.yaml`，其中回环保持开启但使用了适合
重复平行垄道的收紧阈值。脚本不会连接串口、树莓派或真实小车。

## 4. 首轮地图通过门槛

首轮建图不加入障碍，完成以下检查后才进入路线跟踪：

1. `/scan`、`/odom`、`/map` 持续发布，且仿真使用 `/clock`；
2. `map -> odom -> base_footprint -> base_link -> laser_link` 各变换只有一个发布者；
3. 地图分辨率为 0.05 m/cell，覆盖范围能够包含 8×6 m 场地；
4. `farmland_map_validation.log` 通过，三条垄、四条边界在地图中形成连续可辨识结构，
   没有明显双影；
5. 固定轨迹回到起始走廊后，起始位置与垄边重新对齐；
6. `.yaml + .pgm` 和 `.posegraph + .data` 均保存，日志与配置文件同目录归档。

通过后再单独增加静态障碍场景，最后才把 `spore_patrol_route_validation` 的路线
跟踪接入仿真。首轮地图测试不连接真实底盘，不发布真实车辆的 `/cmd_vel`。

## 5. 真实小花园搭建清单（后续现场）

- 占用许可、卷尺、地面胶带、泡沫板/纸箱或交通锥、四角测量基准点；
- 按 8×6 m（空间不足时等比例缩小）放样，记录实际长度、宽度和垄中心线；
- 首轮只布置固定垄边和地头，不放动态障碍；
- 激光高度必须高于地面标线并稳定扫到垄边；
- 标出 ROS 起点、垄中心线、采样点和独立真值基准点；
- 现场必须有独立物理急停人员；建图时先只读检查，低速运动另行授权；
- 真实现场地图必须另存为带日期的地图 ID，不能覆盖仿真地图。

当前开发电脑已实际运行 ROS 2 Humble + Gazebo Classic + SLAM Toolbox，且全程

- 无 GUI 启动烟测通过：`/scan`、`/odom`、`/map` 均可用，进程组退出后无残留仿真进程；

- 结构验收通过：8×6 m 场地覆盖、已知栅格和占据栅格满足阈值；
- 场景几何验收通过：三条垄的覆盖率为 100%、100%、100%，最大轨迹离散约 0.030 m；
- 两次同配置低速运行的重复地图比较通过：两次地图对应垄中心偏移均为 0.050 m，低于 0.150 m 门槛；比较输入为
  `results/sim_farmland_8x6_repeat_20260831/` 与 `results/sim_farmland_8x6_20260831/`，命令为
  `tools/compare_farmland_maps.py`；
- 归档结果：
  `results/sim_farmland_8x6_20260831/`；
- 诊断中曾复现旧宽松回环阈值造成的垄线弯曲，已在正式

这只证明仿真场景、启动链、保存链、首轮地图几何质量和仿真重复性，不证明真实
小花园建图、实机 TF/里程计质量、RTK 精度或比赛指标。现场搭建、实机 rosbag
和实机重复路线仍需在安全条件满足后单独执行。

## 7. 2026-09-12 单垄仿真优化结果

为使单垄结果具备与三垄基线相近的报告可视化效果，单垄场景保留 4.80 m 垄体和
两端各 1.60 m 地头，并增加跨两条行驶通道的短垄头横向标记；没有加入连续侧墙。
仿真驱动改为车体前进 + 地头转向，默认速度 0.12 m/s，保留严格回环参数。

正式结果归档于：
`results/20260912_125950_sim_single_ridge_8m/`

- 地图覆盖：8.00 m × 2.45 m，分辨率 0.05 m/cell；
- 单垄连续检测率：100%；
- 垄线散布：0.054 m，中心线偏移：0.000 m；
- 单垄专用门槛：覆盖率 ≥90%、散布 ≤0.06 m、中心偏移 ≤0.10 m，全部通过；
- 报告图片：`results/report_figures/slam_sim_single_ridge_4p8m.png`；
- 图片生成脚本：`tools/render_slam_report_figures.py`。

该结果用于说明单垄结构在仿真中可以形成连续、可辨识的 SLAM 轮廓；它仍不替代
纸箱场地的实机 rosbag 和真实地图证据。
