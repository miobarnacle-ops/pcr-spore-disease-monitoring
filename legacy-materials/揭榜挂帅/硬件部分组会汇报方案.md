## 一、项目整体理解与硬件定位

本项目核心目标：构建一套**田间自主移动式孢子病害识别系统**，将机器人采集、环境感知与DNA-PCR分子检测技术结合，实现作物病害的早期快速诊断。

硬件部分的三大命题：
- **移动平台**：田间非结构化环境下的自主导航底盘
- **采集装置**：孢子样本的高效采集与预处理机构
- **电控集成**：多传感器融合、PCR模块对接、整机电气系统

## 三、重点贡献方向与方案设想

### 方向一：移动机器人底盘系统

**目标**：设计一台能够在农田非结构化地面稳定行驶、搭载孢子采集与PCR检测模块的移动平台。

**方案设想：**

1. **底盘形式选择**
   - 方案A：履带式底盘——通过性强，适合松软/泥泞农田，但速度较慢
   - 方案B：四轮独立驱动+摇臂悬挂——兼顾通过性与速度
   - **建议采用方案B**，四轮独立驱动配合摇臂悬挂，轮胎选农业花纹宽胎

2. **动力与驱动**
   - 轮毂电机或直流无刷电机+减速器方案
   - 基于STM32F4/F7的主控板，集成电机驱动（DRV8301或ODrive方案）
   - 电池选型：48V锂电池组，续航目标≥4小时

3. **导航与感知**
   - RTK-GPS + IMU 组合导航（田间开阔环境GPS信号良好）
   - 深度相机（RealSense D435i 或 OAK-D）用于近场避障和作物行识别
   - 利用YOLOv11轻量化模型部署到Jetson Orin Nano，实现实时作物行检测与病害视觉预筛

**我的角色**：
- 底盘运动学建模仿真（Isaac Sim中搭建虚拟农田环境）
- 主控PCB设计（电机驱动板 + 传感器接口板）
- 导航算法中视觉感知模块（作物行识别）的模型训练与部署
- 实物样机组装

### 方向二：孢子样本采集与预处理机构

**目标**：设计一套能够在田间自动采集空气或叶面孢子样本，并进行初步处理的机械装置。

**方案设想：**

1. **采集方式**
   - 方案A：空气抽吸式——风扇/气泵抽取空气，通过滤膜富集孢子
   - 方案B：叶面接触式——旋转刷头直接采集叶片表面孢子
   - **建议方案A为主、方案B为辅**，空气抽吸式覆盖范围大，接触式针对重点植株

2. **预处理流程**
   - 滤膜收集 → 洗脱液注入 → 振荡混匀 → 微量液体转移至PCR反应管
   - 采用微型蠕动泵+电磁阀控制液路
   - 温控模块保证样本在转运过程中的活性

3. **结构设计**
   - SolidWorks/Fusion 360 进行机构设计
   - 3D打印快速原型验证

**我的角色**：
- 采集装置的电路控制设计（泵驱动、阀控制、温控）
- 控制逻辑编程（样本采集-预处理时序控制）
- 机构原型搭建与测试

### 方向三：整机电气与控制系统集成

**目标**：将底盘、采集机构、PCR模块、通信模块整合为统一的电气系统。

**方案设想：**

1. **系统架构**
   ```
   ┌─────────────────────────────────────────────┐
   │                 工控机 (Jetson Orin Nano)      │
   │   视觉处理 / 导航决策 / 任务调度 / 数据管理      │
   └──────┬──────────┬──────────┬────────────────┘
          │ CAN/USB  │ UART     │ Ethernet
   ┌──────▼──┐ ┌─────▼────┐ ┌──▼──────────┐
   │ 底盘MCU  │ │ 采集MCU   │ │ PCR分析模块   │
   │ STM32F4 │ │ STM32F1  │ │ (商用模块)    │
   └────┬────┘ └────┬─────┘ └─────────────┘
        │           │
   ┌────▼────┐ ┌───▼──────────┐
   │电机/编码│ │泵/阀/温控/传感│
   │IMU/GPS  │ │器模块         │
   └─────────┘ └──────────────┘
   ```

2. **通信方案**
   - 底盘与采集模块内部采用CAN总线
   - 工控机与各MCU间采用USB转串口/CAN
   - 与远端服务器通过4G/5G模块通信（上传检测结果、接收调度指令）

3. **供电系统**
   - 48V主电池 → 各电压轨（12V/5V/3.3V）通过DC-DC模块
   - 分区域独立供电，关键模块双路冗余
   - 电池电量监测与低电量自动返航

**我的角色**：
- 整机电气原理图设计
- 各PCB板的绘制、打样、焊接与调试
- 线束设计与制作
- 整机电气联调

### 方向四：仿真验证与算法预研

**目标**：在实物样机完成前，利用仿真环境验证底盘控制与导航算法。

**方案设想：**

1. **仿真环境搭建（Isaac Sim）**
   - 构建包含起伏地形、作物行、障碍物的虚拟农田场景
   - 导入底盘URDF模型，配置传感器（相机/IMU/GPS）
   - 验证底盘运动学模型与路径跟踪算法

2. **强化学习导航预研**
   - 在仿真环境中训练农田垄间导航策略（PPO/SAC算法）
   - 以RGB-D图像+IMU数据为观测，底盘速度/转向为动作
   - Sim-to-Real迁移策略预研（域随机化）

3. **视觉模型预训练**
   - 使用YOLOv11构建孢子病害早期症状的田间图像检测模型
   - 模型轻量化（剪枝/量化/知识蒸馏）后部署至Jetson边缘端
   - 目标：推理速度≥15fps，mAP@0.5≥0.85

**我的角色**：
- 仿真环境搭建主力
- RL训练实验
- 视觉模型训练与部署
