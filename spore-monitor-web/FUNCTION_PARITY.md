# 软著功能迁移对照表

功能基准：`main_inspection_system_v4_compliance.py`

## 路径规划

- 卫星/多光谱底图导入、底图适配检查
- 点击标定不规则边界、首边比例尺、闭合、撤销、缩放和平移
- 五组原始参数预设、自定义预设保存与 JSON 导入
- 垄线候选池、评估格网、贪心覆盖选点
- 地头绕行距离、最近邻初始路线、2-opt 改善
- 多轮采样点、覆盖率、平均置信度、路程和时间统计
- 历史项目保存/恢复/删除、工作会话保存/恢复
- JSON、TXT、批量导出、坐标验证、采样密度建议

## 田间检测

- 中/高风险阈值、覆盖半径、巡检间隔
- 均匀/热点/渐变/双区四种原始模拟分布
- 地图或表格选点、单点读取、顺序全检、停止、重置
- 浊度热力图、覆盖圈、风险着色、统计和农技建议
- 粗定检测 CSV 导出

## PCR 分析

- 六类原始靶基因/引物信息和标准曲线参数
- CSV 导入、样本选择、Ct 录入、稀释倍数和质量标记
- Ct-浓度换算、强阳性/阳性/弱阳性/阴性判定
- 批量模拟、标曲重算、粗精融合热力图
- 粗定与 PCR Pearson 相关/定性符合率分析
- LOD 检查、Z 分数离群检查、快速统计和清空
- CSV、TXT、GeoJSON 导出

## 扩散预测与看板

- PCR 源点加载
- 风速、风向、温度、湿度、云量和日/夜参数
- DI、LAI、株高表型参数
- 粗测对数空间趋势、PCR 稳健标定与残差校正融合，PCR 网格权重约 82%–96%
- 贝叶斯粒子滤波源项同化（数字孪生闭环）：从 ≥2 个有效 PCR 观测反演疑似侵染源位置/强度及不确定椭圆，随巡检轮次持续修正（观测不足自动降级并提示）
- 以完整融合场为初始条件、同化源播种的逐时平流—扩散—沉降—再释放演化模型，支持真实风场时序导入
- 冠层有效风速、Pasquill 湍流扩散、温湿度适生性、病情指数和叶面积指数修正（命运速率全部文献参数化，见 ENGINE.md）
- 3/5/7 天统一网格预测，输出峰值、P90、均值和田块内风险分区
- 3/5/7 天风险热力图和风险分区摘要
- 侵染窗口 × 剂量-响应 × 潜育期耦合，输出 3/5/7 天逐格发病概率（提前预警硬指标）
- 高斯烟羽 A/B 对照：地图一键切换稳态烟羽对照渲染，PCR 观测点处 log10 RMSE/偏差量化表（差异度佐证）
- 预测 TXT、CSV、多维 HTML 报告导出（含源项估计与侵染结论）
- 风险分布、浊度-PCR 散点和标准曲线决策看板

> 扩散引擎架构、方法学与引用详见 ENGINE.md；离线标定/对照实验管线见 python-pipeline/。
