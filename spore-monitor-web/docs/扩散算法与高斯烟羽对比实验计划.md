# 重构扩散算法与高斯烟羽模型对比实验计划

> 版本：v1.0  
> 编制日期：2026-09-06  
> 适用项目：基于机器人与 DNA-PCR 技术的孢子病害识别关键技术研究  
> 实验对象：重构后的孢子扩散算法与原始高斯烟羽模型（Gaussian Plume Model）

## 1. 计划目的

通过统一、可复现且具有独立验证数据的对比实验，评估重构扩散算法相对于原始高斯烟羽模型在稳态和动态农田场景中的表现，为最终研究报告中的“扩散预测算法创新”提供数据、图表和方法依据。

本计划重点回答四个问题：

1. 在高斯烟羽模型擅长的稳态、均匀风场场景中，重构算法是否保持合理结果；
2. 在风向变化、冠层衰减、降雨清除、再释放等动态条件下，重构算法是否更符合独立观测或参考数据；
3. PCR 观测源项同化、动态风场、孢子命运过程分别带来多少增益；
4. 算法优势是否在不同随机种子、不同观测密度和不同噪声水平下保持稳定。

## 2. 对比对象

### 2.1 基线：原始高斯烟羽模型

基线使用项目已有的 `gaussianPlume()` 实现，主要特点：

- 单一、连续点源；
- 风速和风向在计算期内恒定；
- 稳态解析解；
- 使用 Pasquill 稳定度参数描述横向和垂向扩散；
- 适合连续排放、均匀地形和稳定气象条件；
- 不描述逐小时风场变化、融合初始场和病情再释放过程。

### 2.2 实验组：重构后的扩散算法

实验组使用当前 `runDispersionForecast()` / `runForecast()` 实现，主要特点：

- 粗测趋势与 PCR 浓度的融合基准场；
- 基于 PCR 观测的源位置及相对源强估计；
- 逐小时平流、邻域扩散、存活损失和再释放演化；
- 支持时序风速、风向输入；
- 考虑温湿度、光照、降雨、LAI 和病情指数；
- 输出 3、5、7 天空间浓度场；
- 可进一步耦合病害侵染窗口。

### 2.3 必须统一的实验条件

两种模型必须使用同一组：

- 地块范围、坐标系和输出网格；
- 源位置和源强设定；
- 初始观测时刻；
- 风场和气象输入；
- 预测时长；
- 独立验证点位置；
- 浓度下限和评价指标。

不得为某个模型单独挑选更有利的场景、参数或验证点。

## 3. 结论边界

当前 Web 页面中的 A/B 数值由同一批 PCR 点参与源估计并再次计算误差，只能称为“回代拟合诊断”，不能作为正式预测准确率。

最终报告中的正式对比必须满足：

- 模型拟合数据与评价数据分离；
- 当前时刻数据与未来时刻数据分离；
- 所有实验场景预先登记，不删除不利结果；
- 合成实验、半实物实验和田间实验分别标注；
- 没有真实田间数据时，只能声称“合成场景性能”，不能声称达到真实病害预警准确率。

## 4. 实验总体设计

实验分为三个层级。第一层必须完成，第二、三层根据设备和场地条件推进。

### 4.1 第一层：可控合成场景

目标：在已知源位置、源强和真实浓度场的条件下，评价模型的可解释性、鲁棒性和动态适应能力。

参考真值不能只采用与实验组完全相同的粗网格模型。建议同时设置：

1. **解析真值组**：由高斯烟羽模型生成，验证实验组在稳态条件下不会异常退化；
2. **高分辨率数值真值组**：使用更细网格、更小时间步的数值求解结果，评价动态场景；
3. **扰动真值组**：在真值中加入风场误差、观测噪声和缺测，评价鲁棒性。

### 4.2 第二层：半实物或受控场景

目标：用风扇、可测颗粒物/示踪物或受控孢子替代物形成可重复释放，验证空间传播趋势。

最低记录内容：

- 释放点坐标和释放持续时间；
- 风速、风向和时间戳；
- 各传感器位置；
- 采样开始与结束时间；
- 每个观测点的原始值；
- 场地照片和布置图。

如果使用颗粒物或示踪物替代孢子，报告中必须写明其粒径和沉降特性与真实孢子的差异。

### 4.3 第三层：小花园/田间验证

目标：使用连续巡检批次形成真正的时间外验证。

- 第 0 次巡检：建立融合场并估计源；
- 后续巡检：作为 T+3、T+5、T+7 或更短时间尺度的独立观测；
- 不得把同一批 PCR 结果同时用于源估计和预测评分；
- 每个场景至少重复 3 次，推荐 5 次；
- 保存天气、路线、采样点、PCR 原始记录和模型输出。

## 5. 场景矩阵

### 5.1 基础场景

| 编号 | 场景 | 风场 | 源项 | 目的 |
|---|---|---|---|---|
| S1 | 稳态基准 | 恒定风速、恒定风向 | 单源连续释放 | 高斯烟羽优势场景，检查实验组是否明显退化 |
| S2 | 风速变化 | 低—中—高分段变化 | 单源 | 验证时序风速适应性 |
| S3 | 风向转变 | 预测期内转向 45°、90° | 单源 | 验证动态风向下的烟羽转移 |
| S4 | 昼夜周期 | 风、温度、湿度、光照周期变化 | 单源 | 验证逐小时气象演化 |
| S5 | 降雨清除 | 中途加入降雨事件 | 单源 | 验证浓度衰减和风险区收缩 |
| S6 | 冠层差异 | 设置不同 LAI、株高 | 单源 | 验证冠层风衰减敏感性 |
| S7 | 多热点初始场 | PCR 融合场含多个高值区 | 单源或多热点 | 验证非单一稳态烟羽场景 |
| S8 | 观测不完整 | 缺测、存疑样本、异常值 | 单源 | 验证同化和输入质量控制 |

### 5.2 观测密度与噪声组合

每个基础场景至少叠加以下条件：

| 因素 | 建议取值 |
|---|---|
| 有效观测点数量 | 4、8、16、32 |
| PCR 对数噪声标准差 | 0、0.15、0.30、0.50 log10 |
| 风向误差 | 0°、±10°、±25° |
| 风速相对误差 | 0%、±10%、±25% |
| 缺测比例 | 0%、20%、40% |
| 随机种子 | 至少 10 个固定种子，推荐 30 个 |

若计算量受限，最低配置为：S1、S3、S5、S8 × 3 个观测密度 × 3 个噪声等级 × 10 个随机种子。

## 6. 数据划分

### 6.1 合成实验

- 训练点：用于 PCR 融合和源估计；
- 验证点：仅用于参数选择；
- 测试点：仅用于最终指标计算；
- 建议比例：60% / 20% / 20%；
- 空间上应覆盖上风向、下风向、中轴线和横风方向。

### 6.2 多轮巡检数据

- 第 n 轮以前的数据：训练和同化；
- 第 n+1 轮数据：预测评价；
- 不允许随机打乱时间后再划分；
- 同一采样点不同时间的数据必须保留时间顺序。

### 6.3 参数冻结

测试集运行前冻结：

- 两种模型的参数版本；
- 浓度下限；
- 网格分辨率；
- 评价点；
- 随机种子；
- 风场插值方式；
- 风险阈值。

测试完成后不得根据测试结果重新调参。

## 7. 对比组与消融实验

至少保留以下四组：

| 组别 | 模型配置 | 用途 |
|---|---|---|
| G0 | 原始高斯烟羽 | 基准模型 |
| E0 | 重构算法，但不使用源项同化 | 评价时序扩散本身 |
| E1 | 重构算法 + 源项同化，恒定风 | 评价源反演增益 |
| E2 | 完整重构算法 + 源项同化 + 时序风场 | 最终实验组 |

如报告篇幅有限，正文展示 G0 与 E2，E0/E1 放入附录，用于说明创新来源。

侵染窗口属于扩散结果的下游应用，不应混入浓度场 RMSE。侵染风险应单独评价。

## 8. 评价指标

### 8.1 浓度预测指标

在 `log10(max(C, floor))` 空间计算：

- RMSE；
- MAE；
- Bias；
- Pearson 或 Spearman 相关系数；
- 预测值落入 2 倍、5 倍误差范围的比例。

### 8.2 空间分布指标

- 高风险区域 IoU；
- 高风险区域 Precision、Recall、F1；
- 峰值位置误差；
- 浓度质心距离误差；
- 下风向主轴方向误差；
- 超阈值区域面积误差。

### 8.3 源项估计指标

- 源位置欧氏距离误差；
- 源强 log10 误差；
- 不确定区间覆盖率；
- 低、中、高置信度与实际误差的对应关系。

### 8.4 工程指标

- 单次运行时间；
- 峰值内存；
- 不同网格尺寸下的耗时；
- 输出确定性；
- 缺测或非法输入时的降级行为。

### 8.5 侵染风险指标

只有存在独立病害标签时才计算：

- ROC-AUC、PR-AUC；
- 灵敏度、特异度、F1；
- Brier Score；
- 提前预警时间；
- 预测概率校准曲线。

没有真实发病标签时，只展示侵染窗口情景分析，不报告分类准确率。

## 9. 统计分析

- 每个场景报告均值、中位数、标准差和四分位区间；
- 对主要指标使用 bootstrap 计算 95% 置信区间；
- 同一场景下比较两种模型时使用配对差值；
- 同时报告绝对差值和相对改善率：

```text
相对改善率 = (基线误差 - 实验组误差) / 基线误差 × 100%
```

- 基线误差接近零时不使用百分比改善率；
- 不只报告平均值，应展示失败场景和最差结果；
- 不强行追求固定的“30% 提升”，以实际数据为准。

建议的阶段性判定标准：

1. S1 稳态场景中，重构算法主要误差不应比高斯烟羽恶化超过 10%；
2. S3/S4/S5 动态场景中，重构算法的 RMSE、空间 IoU 或峰值位置误差应至少有一项稳定改善；
3. 改善方向应在多数随机种子和重复实验中一致；
4. 若只有部分场景改善，应把创新点表述为“动态复杂条件适应性”，而不是“全面优于”。

## 10. 需要先处理的数据口径

正式实验开始前必须冻结以下内容：

1. PCR 标准曲线输出的单位；
2. 采样空气体积、洗脱体积、稀释倍数、捕获效率和提取回收率；
3. PCR 反应体系浓度到空气等效浓度的换算；
4. 源强、网格浓度、沉积量和侵染剂量的单位；
5. 风向采用气象来向还是运动去向；
6. 所有传感数据的时间戳和采样时间窗。

在单位链未完成前，实验结果应标记为“相对浓度/合成浓度”，不得写成真实 `copies/m³`。

## 11. 实施步骤

### 阶段 A：实验协议冻结（1 个工作日）

- 确认比较模型和版本；
- 冻结场景矩阵、数据划分和指标；
- 记录 Git commit、依赖版本和随机种子；
- 建立实验清单，先登记后运行。

交付物：实验协议、场景配置、指标定义。

### 阶段 B：合成实验运行（2 个工作日）

- 运行解析真值组；
- 运行高分辨率数值真值组；
- 运行风场、噪声、缺测和观测密度组合；
- 保存每次运行的输入、预测和指标；
- 不覆盖失败运行。

交付物：原始预测结果、逐场景指标、运行日志。

### 阶段 C：消融和鲁棒性分析（1 个工作日）

- 比较 G0/E0/E1/E2；
- 分析源项同化和时序风场的独立贡献；
- 分析参数敏感性；
- 汇总失败条件和适用边界。

交付物：消融表、敏感性图、适用范围说明。

### 阶段 D：半实物或田间补充（视场地安排）

- 布置释放源和独立观测点；
- 同步记录天气和采样时间；
- 至少完成 3 次重复；
- 按时间划分训练和测试；
- 输出真实场景指标。

交付物：现场记录、原始数据、照片/视频、评价结果。

### 阶段 E：报告材料整理（1 个工作日）

- 生成统一配色的热力图；
- 生成误差箱线图、场景分组柱状图和源位置误差图；
- 制作主结果表和消融表；
- 撰写方法、实验设置、结果、讨论和局限性；
- 核对每个结论是否有对应数据文件。

交付物：报告章节草稿、图表、可复现说明。

## 14. 创新点表述模板

可在获得实验结果后按实际数值填写：

> 针对传统高斯烟羽模型依赖稳态风场、单一连续点源且难以融合巡检观测的问题，本项目构建了 PCR 观测驱动的孢子扩散预测框架。该方法先融合粗测与 PCR 结果形成空间基准场，再估计潜在源位置和相对源强，并通过逐小时风场驱动的平流—扩散—损失—再释放过程生成 3、5、7 天风险分布。对比实验显示，在【具体动态场景】下，本方法相对高斯烟羽模型的【指标】改善【实际数值及置信区间】；在稳态场景中，两者表现【实际结论】。结果表明该方法的主要优势在于【由实验支持的优势】，而非在所有条件下无条件优于传统模型。

## 15. 风险与应对

| 风险 | 影响 | 应对措施 |
|---|---|---|
| 缺少真实未来观测 | 无法证明 3/5/7 天预测准确率 | 先完成合成实验，真实结论保持待验证 |
| PCR 单位链不完整 | 浓度和源强缺少物理意义 | 单位冻结前统一标记为相对浓度 |
| 高分辨率真值偏向数值模型 | 对实验组有利 | 同时增加解析真值组和受控实验 |
| 场景数量过多 | 计算和整理成本过高 | 先完成 S1/S3/S5/S8 最小矩阵 |
| 重构算法并非所有场景更优 | 创新结论不稳定 | 将创新定位为动态条件适应性，完整报告失败场景 |
| 参数调优造成测试泄漏 | 结果失真 | 测试前冻结参数和场景，保留实验清单 |

## 16. 完成标准

本对比计划完成需要同时满足：

- 至少完成 4 类场景和 10 个随机种子；
- 高斯烟羽和重构算法使用同一输入及测试点；
- 训练、验证和测试数据明确分离；
- 输出浓度误差、空间误差、源估计误差和运行效率；
- 至少完成 G0/E0/E1/E2 四组消融；
- 图表均可追溯到原始数据；
- 报告明确区分合成、半实物和田间结果；
- 所有创新结论均附实际数值和不确定区间；
- 不以回代拟合误差冒充未来预测准确率。
