# 报告对比实验与模拟数据工作计划

版本：v1.0  
日期：2026-09-06  

## 1. 目标与结论边界

目标是在无法取得真实农田数据的前提下，用透明、可复现的模拟实验说明：相较于传统单风场、稳态高斯烟羽模型，重构后的动态扩散算法在风向变化、时变释放和降雨清除等非稳态环境中能更准确地恢复传播范围、热点位置和浓度梯度。

报告必须把数据标注为“合成模拟数据”，不能使用“田间准确率”“真实预测提升”等表述。实验应主动保留一个稳态对照场景，让高斯烟羽在其适用条件内有机会占优。这样最终结论是“重构算法在复杂动态场景中更优”，而不是不可验证的“所有场景均更优”。

## 2. 当前算法仍需完善的内容

### P0：正式报告前必须完成

| 项目 | 当前问题 | 最小完善方式 | 完成判据 |
|---|---|---|---|
| 平流位移物理量 | `runForecast` 当前用 `风速 × 时间 × 沉降速度` 计算水平位移，量纲和物理含义不成立 | 将水平输送与沉降损失拆开；水平位移只由近冠层有效风速和无量纲输送折减决定，沉降速度只进入沉降损失 | 恒定风场下传播中心速度与设定有效风速一致，改变沉降速度不会改变水平传播方向和速度 |
| 时变天气驱动 | 当前只有风速、风向可传入时间序列；温湿度、光照和降雨在整个预测期内固定 | 在现有 ForecastOptions 中补充逐小时天气序列；每小时重新计算存活、雨洗和再悬浮率 | 阵雨开始后浓度明显衰减，雨停后不再重复施加整段降雨量 |
| 离线模型与网页模型一致性 | 当前 Python Eulerian 对照是“离线近似”，不是 TypeScript 运行时的逐项等价实现 | 固定 3 个小型场景，对相同输入导出两端网格快照，并设置峰值、均值和热点范围容差 | 三个场景均通过快照和指标容差检查 |
| 独立评估 | 网页内 A/B 诊断仍使用参与源估计的 PCR 点评分 | 报告只使用独立模拟参考和留出点；网页回代结果不进入正式结论 | 训练点仅用于尺度校准，所有表格指标来自留出点 |

### P1：提升可信度，但不要求新增生产模块

1. 对每个场景运行 3 个随机种子，报告均值与范围，避免单次噪声带来的偶然优势。
2. 对风速、扩散系数、雨洗系数做 ±20% 敏感性分析，确认结论不依赖单一参数。
3. 同时报告 RMSE、MAE、空间相关系数和热点 IoU，不只选取最有利的一个指标。
4. 热力图统一色标，并额外展示绝对 log10 误差图，避免通过各自缩放色标制造视觉差异。

## 3. 模拟数据设计

### 3.1 独立参考生成器

采用时间积分的动态高斯烟团集合生成“合成参考场”。每个时段释放一个烟团，烟团中心根据逐分钟风场积分移动，并独立考虑纵向/横向扩散、紫外与沉降损失、阵雨清除。它与用于预测的粗网格 Eulerian 方法不是同一种离散求解器，从而降低“用同族模型生成真值再证明自己”的偏置。

### 3.2 统一实验条件

| 项目 | v1 设置 |
|---|---|
| 空间范围 | x = -2–18 km，y = -7–7 km |
| 网格间距 | 250 m |
| 模拟时长 | 6 h |
| 场景数 | 3 |
| 观测点 | 每场景 80 点 |
| 校准/测试 | 20 个校准点、60 个留出测试点 |
| 观测噪声 | log10 空间标准差 0.12 |
| 随机种子 | 20260906 |
| 对比基线 | 单一平均风场的稳态高斯烟羽 |
| 重构方法 | 时变风场、时变释放和损失驱动的粗网格动态 Eulerian 离线代理 |

两种候选模型都允许在同一批 20 个训练点上拟合一个浓度尺度因子，所有结果在未参与校准的 60 个点上计算。

### 3.3 场景矩阵

| 场景 | 作用 | 预期 |
|---|---|---|
| S1 稳定风场、无雨 | 公平性和退化能力对照 | 高斯烟羽应具有竞争力，重构算法不必强行胜出 |
| S2 六小时风向转折 | 检验弯折传播带和历史风场记忆 | 动态算法应明显优于单一直线烟羽 |
| S3 风向变化、阵雨清除、时变释放 | 检验非稳态输送和损失过程 | 动态算法应在热点位置和总体误差上优于高斯烟羽 |

## 4. 报告评价指标

1. 留出点 log10 RMSE：主指标，衡量跨数量级浓度误差。
2. 留出点 log10 MAE：降低少数大误差对结论的影响。
3. Pearson 相关系数：衡量空间浓度梯度的一致性。
4. 热点 IoU：以合成观测 70 分位阈值定义热点，衡量风险区域重叠程度。
5. 热力图：参考场、重构算法、高斯烟羽使用同一色标。
6. 误差热力图：重构算法和高斯烟羽使用同一误差色标。

## 5. 执行步骤

### 阶段 A：建立可复现实验

- 固化随机种子、空间范围、风场、降雨和释放率。
- 输出逐点合成观测 CSV、场景指标 CSV/JSON、三组热力图和指标柱状图。
- 保存一条命令即可完整重跑的脚本。

### 阶段 B：完成算法 P0 补救

- 修正水平平流位移的物理量。
- 在现有配置结构中增加逐小时天气输入，不创建新的业务模块。
- 建立 Python 离线代理与 TypeScript 运行时的三个固定场景快照测试。

### 阶段 C：最终实验

- 每场景运行 3 个随机种子。
- 汇总平均值和最小/最大范围。
- 对风速、扩散和雨洗参数做轻量 ±20% 扰动。
- 若动态场景中重构算法的 RMSE、相关性和热点 IoU 至少两项稳定优于高斯基线，则形成正式结论。

### 阶段 D：写入报告

建议按以下顺序展示：

1. 先说明高斯烟羽的稳态假设和重构算法增加的动态过程。
2. 展示 S1，说明高斯模型在假设成立时简单而有效。
3. 展示 S2/S3 的统一色标热力图和误差图。
4. 展示留出点指标表和柱状图。
5. 最后说明模拟数据边界和无法获得真实农田数据的限制。

## 6. 当前 v1 结果及其意义

| 场景 | 重构 RMSE | 高斯 RMSE | 结果 |
|---|---:|---:|---|
| S1 稳定风场 | 0.720 | 0.437 | 高斯低 39.4% |
| S2 风向转折 | 1.476 | 3.497 | 重构低 57.8% |
| S3 风向变化与阵雨 | 1.267 | 3.200 | 重构低 60.4% |

S2/S3 的平均 RMSE 从高斯模型的 3.349 降至重构方法的 1.372，降低约 59.0%。S1 中高斯模型更优，证明实验没有把所有场景都设计成必然支持重构方法；重构算法的创新价值应被定位为对非稳态复杂环境的适应能力。

## 7. 推荐报告措辞

> 在独立动态烟团生成的合成参考场中，稳态条件下传统高斯烟羽仍保持较低误差；当风向发生转折或同时存在阵雨清除和时变释放时，动态重构算法的留出点 log10 RMSE 分别降低 57.8% 和 60.4%，并能更好地恢复弯折传播带和热点区域。这说明重构的主要价值不是替代所有稳态模型，而是提升复杂时变环境下的空间表达能力。

必须紧接以下限制说明：

> 上述结果来自透明可复现的合成数值实验，不是实际农田观测，不能解释为真实田间准确率。由于无法获取实测数据，本研究通过独立生成器、留出评估、稳态对照和参数敏感性分析降低模拟验证的偏差。
