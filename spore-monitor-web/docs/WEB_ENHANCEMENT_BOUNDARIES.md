# Web 继承行为与增强边界

> 生效日期：2026-08-30  
> 适用对象：`spore-monitor-web`  
> 参考来源：`揭榜挂帅.zip/软著/main_inspection_system_v4_compliance.py`（SHA-256 见同目录审计文档）

## 原则

Web 控制台继承软著的核心业务语义，但不是 Python 程序的逐行或逐数值复刻。后续实现遵循以下规则：

1. 明确继承的算法、导出字段和冻结接口应有兼容性夹具与自动化测试。
2. 为修复缺陷、支持机器人整合或提升模型而发生的 Web 变化可以保留；必须说明变化、适用边界和测试方式。
3. 新增能力不倒填为软著已有或实测能力。
4. 车辆任务格式仍遵循 `route_v1.json` / `schema_version: "1.0"` 的冻结约束，见 `ROUTE_SCHEMA.md`。

## 当前边界清单

| 范围 | Web 策略 | 自动化依据 |
|---|---|---|
| 旋转、点在多边形内、扫描线交点、面积 | 继承 Python 业务语义 | `tests/parity/soft-copyright.test.ts` |
| 覆盖选点、闭合巡检路线、统计摘要 | 继承“边界内选点、按轮次生成闭合路线、产出距离和时间”的业务语义；不锁定旧网格步长或候选数 | 同上 |
| 规划输入校验 | Web 增强：在规划前拒绝非有限坐标、重复顶点、自交边界和非正参数，避免无效几何进入路线接口 | 同上 |
| 多边形重心 | 有意修正：使用有向面积，避免软著实现对特定顶点方向产生负号错误 | 同上，固定错误样例与正确值 |
| 风险阈值、Pasquill 稳定度分级 | 继承阈值边界 | 同上 |
| PCR Ct→浓度、定性结论、Ct 离群检测 | 继承计算/判定边界与 `|Z| > 2.5` 规则；Web 将离群检测下沉为可复用计算层，保留类型安全校验 | 同上 |
| PCR 粗精比较 | 继承 Pearson 相关与高/低风险符合率的计算语义 | 同上 |
| Gaussian plume | 增强：引入受体高度、镜像源和沉降项；不以旧数值为回归目标 | 同上仅校验上风向为零与非负性；扩散引擎测试另行覆盖 |
| 3/5/7 天预报输出 | Web 的融合平流—扩散模型；保持时间窗、稳定度、网格和汇总字段可供控制台使用，不复制旧预测网格或公式 | 同上及 `tests/engine/*.test.ts` |
| 粒子滤波、逐时扩散、感染风险、A/B 对照 | Web 新增/增强能力 | `tests/engine/dispersion.test.ts` |
| 机器人监控、SLAM 地图、数据源抽象 | Web 新增整合能力，尚未构成实机验证 | 后续 W3–W5 的接口与 Mock/Replay 测试 |

## 运行方式

```bash
npm run test:parity
```

夹具位于 `tests/fixtures/soft-copyright/v4-core-compatibility.json`。它记录参考源哈希、继承用例、已知修正和增强模型边界；更新时必须同步修改本文件与 Python→Web 审计。
